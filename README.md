# 📺 Rate My Show

Um blog de séries com estética inspirada no [Letterboxd](https://letterboxd.com/), onde eu compartilho as séries que assisti e o que achei delas.

🔗 **Acesse o site:** [link do GitHub Pages](https://natalialambert.github.io/rate-my-show)

## 📖 Sobre o projeto

O **Rate My Show** nasceu como projeto da disciplina de **Desenvolvimento de Sistemas** do curso Técnico em Informática do **IFTO – Campus Paraíso do Tocantins**, e foi apresentado na própria matéria.

A ideia era criar um espaço para registrar e avaliar séries com o visual e a vibe do Letterboxd. Por enquanto, ele funciona como um **blog**: eu publico as séries que assisti, e o site as exibe de forma organizada e visualmente agradável.

## ✨ Funcionalidades atuais

- Blog com as séries que assisti
- Visual inspirado no Letterboxd
- Hospedado no GitHub Pages

## 🚧 Status do projeto

Este projeto foi desenvolvido em uma fase **inicial**, dentro do prazo e do escopo da disciplina. Ainda há muito espaço para evoluir.
